## 🛠️ Core Concepts Covered

* **Two Pointers:** Used for optimized in-place array modifications (`Remove Element`, `Rotate Array`) and element matching.
* **Greedy Algorithms:** Ideal for solving optimization problems like maximizing profits or tracking reachable steps (`Jump Game`, `Gas Station`, `Candy`).
* **Simulation & String Parsing:** Handling string alignment, text rules, and transformations (`Zigzag Conversion`, `Text Justification`).
* **Prefix/Suffix Arrays:** Precomputing structural constraints to handle array geometry and products (`Product of Array Except Self`, `Trapping Rain Water`).
